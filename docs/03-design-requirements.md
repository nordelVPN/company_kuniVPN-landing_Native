# Требования к дизайну kuniVPN

## Источники и направление

Основной визуальный источник — [desktop home](images/consept/desktop/01-home.png), далее desktop 02–09. Фирменный знак — [logo-refined-03](images/consept/desktop/logo-refined-03.png). Мобильные 01–09 обязательны как референсы компонентов, состояний и мобильной композиции. Адаптивную версию index и служебных страниц дополнительно проработать под эти принципы, без корпуса телефона вокруг всего сайта.

Характер: энергичный технологичный бренд с уличной графикой. Почти чёрный фон, яркий оранжевый акцент, тёплый белый текст; крупные плотные заголовки, наклонные акцентные слова, рваная бумага, маркерные стрелки, короны, молнии, шахматные фрагменты. Важна иерархия и читаемость поверх насыщенных иллюстраций.

## Палитра первого прохода

Значения ниже предложены для реализации; это не подтверждённые исходные цвета макета. После сравнения оригиналов уточнять централизованно.

| Токен | Значение | Применение |
|---|---|---|
| --bg | #080808 | основной фон |
| --surface | #151515 | карточки и формы |
| --surface-raised | #222222 | внутренние панели |
| --text | #F7F2E8 | заголовки и основной текст |
| --muted | #B9B5AD | вторичный текст |
| --accent | #FF7A00 | CTA, активные элементы, бренд |
| --accent-hover | #FF941F | hover |
| --on-accent | #080808 | текст оранжевой кнопки |
| --border | #45413B | разделители и поля |
| --success | #70C88A | подтверждённый успешный статус |
| --danger | #FF7777 | ошибки форм |
| --focus | #FFD08A | клавиатурный фокус |

Светлая тема не подтверждена концептами сайта. Белое поле в вариантах логотипа не задаёт отдельную тему сайта. Контраст обычного текста — не ниже 4.5:1, крупного — 3:1, значимых границ и состояний — 3:1; проверять реальные сочетания.

## Типографика

Точный шрифт по PNG не установлен. Нужен плотный гротеск для заголовков и читаемый гротеск для текста; финальную гарнитуру выбрать по визуальному сравнению и лицензии. При русском контенте обязательна качественная кириллица. Не выдавать похожий шрифт за оригинальный.

| Роль | Desktop, стартовое значение | Mobile web |
|---|---|---|
| H1 | 64–88 px / 0.98–1.05, 800–900 | 38–48 px / 1.05 |
| H2 | 40–56 px / 1.1, 800 | 28–36 px / 1.12 |
| H3 | 22–28 px / 1.2, 700 | 20–24 px |
| Основной текст | 16–18 px / 1.5–1.65 | 16 px / 1.5 |
| Подписи | 12–14 px / 1.4 | 12–14 px |
| Навигация и кнопки | 14–16 px, 600–700 | не менее 14 px |

Размеры адаптируются через clamp; не фиксировать переносы, которые ломают другой язык. Акцентные слова могут быть оранжевыми и курсивными. Длинные абзацы не набирать капсом. Шрифты WOFF2, font-display: swap, только используемые начертания.

## Сетка и геометрия

Стартовый desktop-контейнер: max-width 1280 px, поля 32–48 px; tablet 24 px, mobile 16–20 px. Шаг отступов: 4/8/12/16/24/32/48/64/96. Значения уточняются по оригинальным PNG.

Hero: текст слева, персонаж/коллаж справа; на мобильном текст и CTA идут раньше иллюстрации. Контент не встраивается в растр. Карточки платформ и форм тёмные с тонкой границей; полоса преимуществ features светлая, с тёмным текстом и оранжевыми иконками. Стартовые скругления ориентировочно 12–20 px. Оранжевые CTA с тёмным текстом, download/arrow-иконкой. Минимальная зона взаимодействия 44×44 px.

Стартовые диапазоны: до 600 px одна колонка; 601–900 px адаптивные пары; выше 900 px desktop-композиции. Перестройка определяется вместимостью, а не переносом breakpoint Nordel без проверки. Header превращается в доступное меню до возникновения тесноты.

## Иллюстрации, логотип и инфографика

- На home: персонаж в оранжевой одежде, ноутбук, наушники, крупный брендовый коллаж справа. Нужны отдельные разрешённые к использованию ассеты; PNG целого экрана не заменяет страницу.
- Features: фирменный щит, устройства, графические полосы и карточки преимуществ.
- Apps: устройства и платформенные карточки с согласованными значками ОС.
- Security: многослойный щит и световые оранжевые контуры; схема объясняет защиту, не изображает неподтверждённые гарантии.
- Support: Help Center, поиск, карточки тем, FAQ.
- Plans: сравнение планов, оранжевое выделение рекомендации; цена, валюта и период — обычный текст.
- Mobile app: маскот корги, светящееся кольцо подключения, списки локаций, нижние вкладки. Использовать как отдельный продуктовый референс и возможное демо.
- Иконки интерфейса — единый SVG-набор с согласованной толщиной линии. Не смешивать emoji и случайные пиктограммы.
- Рваные края, короны, стрелки и шахматный узор — декоративные слои: aria-hidden, без перехвата кликов. Декор не пересекает поля, текст и focus ring.
- Логотип использовать по предоставленному исходнику, сохранять пропорции. Не перерисовывать автоматически щит или маскота, если требуется точное совпадение.
- Не добавлять вымышленные страны, скорости, число серверов, отзывы или сертификаты. Демонстрационные данные маркировать.

## Состояния, адаптивность и доступность

У кнопок/полей: default, hover, focus-visible, active, disabled; у запросов: loading, success, error, empty. Ошибка имеет текст, не только цвет. Формы имеют label, autocomplete, связь ошибки с полем. Пароли можно показывать по доступной кнопке.

Одно H1, последовательная структура H2/H3, семантическая навигация, skip-link. Dialog закрывается Escape и возвращает фокус. Анимации короткие, без постоянного мигания; prefers-reduced-motion отключает декоративное движение. Контент и CTA доступны без анимации.

На 320/375/390/768/1024/1440 px отсутствуют горизонтальный скролл, обрезанные кнопки и наложения; при 200% zoom интерфейс сохраняет читаемость. Проверить длинный русский текст отдельно от английского.

## Визуальная приёмка

Сравнить каждую соответствующую секцию index, модальное окно checkout и My Account с оригиналом при одинаковой ширине и масштабе. Сохранять эталон, фактический скриншот и список расхождений: композиция, типографика, цвета, ассеты, интервалы, состояния. Мобильную версию сайта принимать отдельно; концепт телефона не считать её эталоном. Обзорные миниатюры не дают основания заявлять pixel-perfect.

## Обязательные исправления по уточнениям владельца

- Логотип строго по logo-refined-03.png: горизонтальный вариант для header, вертикальный для крупного art входа, отдельный щит для компактных мест. Случайный щит, текстовая имитация и старый знак не принимаются.
- Удалить видимый language-label из header, layout и мобильного меню. Доступное имя оставшегося языкового элемента при его наличии задаётся без лишней видимой подписи; набор языков не выдумывать.
- Ввести светлые токены --paper (стартово #F7F0E1), --on-paper (#151515), --paper-muted (#4D4942). Светлая секция features — часть общей композиции, а не переключаемая светлая тема.
- Однотонный фон features, отдельные верхний/нижний рваные края через ::before/::after с прозрачными PNG. Края независимы, не зеркалить один механически. Их цвет совпадает с секцией, отсутствуют швы на 1x/2x и на всех ширинах; pointer-events:none. Текст не вшит в изображение.
- Art — предметные многослойные композиции из концептов; общие CSS-плашки, абстрактный щит и случайные иконки не заменяют оригиналы.
- Platforms: для каждого типа название, описание, фото компьютера/телефона, CTA и строка версии/Other versions в соответствии с платформой. Не показывать один тип устройства во всех карточках.
- Полностью переработать security и support по [разбору](06-art-and-mobile-review.md), а не ограничиваться перекраской текущих карточек.
- Checkout плавно появляется поверх index: ориентир 180–240 ms opacity/translate, без скачка layout; reduced-motion убирает движение. Backdrop, закрытие, focus trap, Escape и возврат фокуса обязательны.
