# QA-09 — команда start не соответствует README

Статус: конфигурация исправлена, override и Chromium live reload проверены. [Результат](../../qa/rework-result.md).

Ниже сохранён исходный аудит до исправления. Приоритет: P2 · дефект контракта разработки.

Файлы: webpack/webpack.dev.js, README.md, docs/02-architecture-build-ci.md.
Воспроизведение: конфигурация задаёт devServer.port=8081, README и архитектурный контракт обещают localhost:3000. npm start без override использует 8081. Проблема подтверждена чтением фактической конфигурации; браузерный запуск default-порта не проводился, порт 3000 занят существующими процессами.
Привести конфигурацию к утверждённому контракту 3000 либо обновить контракт после решения владельца. Сохранить documented override npm start -- --port 3100. Не завершать чужие процессы при занятом порте.
Приёмка: на свободном стенде npm start сообщает согласованный default URL; override работает; HMR и watch hbs/data/locales/partials проверены фактической правкой с восстановлением файла.
