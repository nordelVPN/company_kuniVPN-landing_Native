# QA-06 — ошибка формы остаётся после исправления

Статус: исправлено и проверено; input снимает устаревшую ошибку только исправленного поля. [Результат и ограничения](../../qa/rework-result.md).

Ниже сохранены факты исходного аудита; они описывают состояние до исправления. Приоритет: P2 · дефект поведения · дополнение REV-09.

Файл: src/modules/main.js, обработчик [data-login].
Воспроизведение: отправить пустую форму; поле получает aria-invalid=true и фокус. Исправить email/пароль без повторного submit. aria-invalid и общий текст ошибки сохраняются: модуль не обрабатывает input/change для этих полей. Подтверждено запуском реального main.js в VM в audit-current.cjs; это проверка обработчиков, не браузер.
Пересчитывать состояние уже проверенных полей при исправлении, очищать устаревшую ошибку и сообщение о предыдущей проверке. Не показывать ошибки до первого взаимодействия/submit. Привязать отдельный текст к соответствующему полю, общее сообщение использовать для статуса.
Приёмка: empty → invalid → correction снимает ошибку сразу или на blur по выбранной стратегии; исправление одного поля не снимает ошибку другого. Повторная отправка, show/hide и смена языка сохраняют корректную связь labels/descriptions. Проверить с клавиатурой и screen reader после появления браузерного стенда.
