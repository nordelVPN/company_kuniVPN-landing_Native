# Задачи переработки kuniVPN

Функциональная реализация и локальные проверки выполнены. Статусы каждого QA/REV и незакрытая послойная графика перечислены в [итоговом отчёте](../qa/rework-result.md#статусы-задач). Ниже сохранены критерии приёмки; они не отменены наличием кода. REV-03 и финальная графическая/ручная приёмка не объявлены закрытыми.

## REV-01 — сверка и реестр инфографики

Основание: [разбор концептов](../06-art-and-mobile-review.md). Индивидуально сверить оригиналы, измерить зоны и завести реестр source/crop/output/alpha/размер/мобильная версия. Для home дополнительно крупно проверить оригинал и правую часть. Учесть все перечисленные слои features/apps/security/support, logo-refined и mobile 01–09.

Приёмка: у каждого art есть предметная спецификация, план выделения и список недоступных исходников; обзорный просмотр не считается подготовкой ассета.

## REV-02 — исправить фирменный знак

Зависит от REV-01. Подготовить горизонтальный, вертикальный и компактный варианты строго из logo-refined-03.png либо точного исходника. Заменить временный знак в header/footer/auth/account и изображениях устройств по возможности.

Приёмка: совпадают форма языка/щита, наклон KUNI, пропорции и VPN; сравнение на чёрном/светлом фоне, desktop/mobile. Никакой текстовой имитации.

## REV-03 — выделить art и рваные переходы

Зависит от REV-01. Подготовить файлы по реестру, отделить предметные группы и декор. Удалить фон там, где требуется alpha; сохранить glow. Не вырезать текст вместе с изображением. Сделать отдельные прозрачные PNG верхнего и нижнего рваного края.

Приёмка: нет кусочков header/соседнего текста, чёрных прямоугольников на светлой секции и обрезанного свечения; оптимизированы размеры и responsive варианты. Недостающий оригинал отмечается явно, временная графика не принимается как финальная.

## REV-04 — единый index и навигация

Изменить webpack/pages.js, pages/index.hbs, общие partials, данные и JS. Объединить home/features/apps/security/support/plans/login в index; #login последний содержательный экран. Удалить лишние страницы из манифеста, checkout вынести в dialog. Добавить forgot-password/create-account/account как отдельные entries.

Убрать видимый language-label в desktop/mobile; не добавлять новые языки без требований. Обновить навигацию и ссылки с внутренних страниц.

Приёмка: один header и H1 на index, уникальные id, якоря не скрыты sticky header; нет переходов к старым отдельным страницам. Прямые служебные URL работают в подпути Pages.

## REV-05 — features со светлой полосой

Зависит от REV-03/04. Пересобрать hero-art со щитом, окнами/курсором, орбитами и декором. Светлая полоса четырёх преимуществ: однотонная section, тёмный текст, оранжевые иконки, разделители. Верх/низ через ::before/::after и PNG рваных краёв. Ниже тёмные сценарии использования.

Приёмка: видны оба неровных перехода без швов, повторяемой пилы и перекрытия текста; мобильная версия имеет читабельные карточки и ту же смену зон.

## REV-06 — platforms

Зависит от REV-03/04. Общий hero из desktop/laptop/phone. Пять карточек Windows/macOS/iOS/Android/Linux: platform icon/name, описание, отдельное фото соответствующего устройства, CTA, secondary/Other versions по данным платформы. Фон карточек с рваной кремово-оранжевой диагональю.

Приёмка: ПК/телефоны соответствуют платформам; нет пяти одинаковых карточек с одной пиктограммой. Версии и download URL подтверждены либо явно отсутствуют; кнопки не ведут в пустые #. На mobile порядок карточек и CTA сохраняется.

## REV-07 — полная переработка security

Зависит от REV-03/04. Левая колонка: заголовок, описание, три icon/text пункта, Download/All Apps и ОС. Правая: объёмный щит, стеклянные панели, платформа, орбита, glow, декор. Удалить временную абстрактную композицию.

Приёмка: узнаваемая композиция оригинала, пропорции и многослойность; на mobile art не перекрывает текст, нет обрезанного glow. Неподтверждённые возможности не публикуются как факты.

## REV-08 — переработка support

Зависит от REV-03/04. Большой заголовок, светлое поисковое поле и Search, chips, книга/щит/чаты справа. Ниже Getting started/Troubleshooting/Account and billing/Contact support с собственными иконками, стрелками и декором. Согласовать локальные статьи/FAQ и контактный канал.

Приёмка: поиск/chips имеют действия, loading/empty/error по способу поиска; карточки ведут к содержимому, клавиатура работает. Mobile — по 09-help, без уменьшенного нечитаемого desktop art.

## REV-09 — Sign In последним экраном

Зависит от REV-02/04. В #login слева refined art, справа Welcome Back to KUNI VPN и форма: email/password/show password/Keep me signed in/Sign In/Forgot password/Create Account.

Приёмка: расположение после plans; формы и ссылки доступны с клавиатуры, ошибки связаны с полями; нет ложного успешного входа. Ссылки ведут на две новые страницы.

## REV-10 — Forgot password и Create account

Зависит от REV-09. Сделать собственные страницы в фирменном стиле. Recovery: email/send/confirmation/retry; reset по токену с новым паролем, подтверждением, invalid/expired token. Registration: email/password/confirmation, необходимые согласия, ошибки и подтверждение по API.

Приёмка: адаптивные макеты и состояния, возврат к #login, корректные autocomplete/labels; отдельные H1/title. При отсутствии API прототип отмечен; не показывать реальный успех отправки.

## REV-11 — плавный checkout dialog

Зависит от REV-04, актуальных тарифов. При выборе каждого плана открыть окно без смены страницы, синхронизировать planId, summary, срок, цену, 5 устройств и условие триала. Добавить email, способ оплаты, итог, Continue to payment, loading/error. Устаревшие URL-тесты выбора тарифа заменить.

Приёмка: 4/4 плана, повторное открытие и смена выбора; плавность 180–240 ms/reduced motion; focus trap, Escape/backdrop/кнопка, возврат фокуса, scroll lock. Mobile по 08-payment, поля доступны при клавиатуре. Реальный платёж только через согласованный provider/backend.

## REV-12 — детальная My Account

Зависит от REV-02/04. Отдельный account.html. Компоненты: account-sidebar, profile-card/edit-profile, subscription-card/status/actions, payment-method, billing-history/row, security, preferences, help-card, sign-out. Данные и состояния — по [спецификации](../04-pages-and-components.md).

Приёмка: Account/Subscription/Billing/Security/Preferences переключают содержимое; профиль редактируется по контракту, история имеет empty/error/loading, карта маскирована, подписка показывает реальные данные. Нет Alex Carter/59.99/10 устройств как реальных значений. Без API — явный прототип. Mobile по 05-account/06-subscription.

## REV-13 — мобильная версия

Зависит от переработанных компонентов. Пройти все mobile 01–09 по таблице разбора; переработать адаптивность index, auth, account и checkout. Для продуктового превью: connect/disconnect, location search/favorites и settings остаются локальным демо. Не переносить OS-рамку на весь сайт.

Приёмка: скриншоты 320/375/390/768, отсутствие overflow, удобные 44px targets, формы с клавиатурой, navigation, длинный текст. У каждого mobile-референса записано, какой компонент/состояние он определяет; исключения объяснены.

## REV-14 — проверки, CI и визуальная приёмка

Зависит от REV-02–13. Обновить check-build/smoke/check-plans под четыре HTML, якоря и dialog. Сохранить CI dev/prod/lint/Pages и root/subpath. Добавить браузерные сценарии checkout, auth navigation, account tabs, support/menu.

Приёмка: команды проходят на чистой установке; Chromium/Firefox/WebKit, 200% zoom, клавиатура, reduced-motion, ошибки консоли/404 проверены. В docs/qa — section-by-section desktop/mobile скриншоты и список реальных расхождений. Старый HTTP smoke не заменяет визуальную приёмку.

## Порядок зависимостей

REV-01 → REV-02/03 → REV-04 → REV-05–12 → REV-13 → REV-14. Настройку шаблонов и nav можно делать после реестра, не ожидая всех изображений; визуальные задачи закрываются только после готовых ассетов и сверки.
