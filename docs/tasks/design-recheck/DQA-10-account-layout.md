# DQA-10 — Вернуть обзорную сетку кабинета и мобильную помощь

Статус: исправлено и проверено; обзор profile/subscription/payment/billing, переходы в детальные tabs и мобильная help-card. Приоритет: P2.

[Исправления и доказательства](../../qa/dqa-fixes.md). Ниже — исходные факты аудита.

Основание: docs/06 Account (профиль/подписка слева, Payment Method/Billing History справа), docs/04 Help и mobile 05/06/09; REV-12/13. Файлы: pages/account.hbs, base.scss.
Факт: default Account показывает только широкую profile-card и View plans; подписка/платежи вынесены полностью в другие вкладки, поэтому исходная обзорная сетка отсутствует. На mobile .help-card скрыта display:none без компактной замены в кабинете; остаётся общий footer Help, поэтому доступ к помощи не исчез полностью, но требуемая карточка/связь mobile Help не реализована.
Исправление: добавить компактный overview с profile/subscription/payment/billing в состоянии empty/demo; вкладки оставить для деталей. На mobile — компактный Help/Contact support рядом с содержимым кабинета.
Приёмка: desktop узнаваем по структуре 09-account без образцов чужой личности/цен; overview не подменяется API-заглушкой одной карточки. На 320–768 помощь доступна внутри кабинета, footer не единственная замена. Demo-состояния и клавиатурная навигация сохраняются.

Доказательства и границы: [повторный аудит](../../qa/design-recheck.md).
