# DQA-07 — Исправить якорный offset при переносе мобильной шапки

Статус: Исправлено и проверено: ResizeObserver, фактическая закрытая шапка, переносы и CSS zoom 200%. Приоритет: P2.

[Исправления и доказательства](../../qa/dqa-fixes.md). Ниже сохранены исходные факты QA и критерии приёмки.

Основание: docs/02/03, REV-04 — якоря не скрыты header. Файл: base.scss scroll-padding/header.
Воспроизведение: viewport 320×900, RU, index.html#help-start; прокрутить #help-start в начало. Header после переноса занимает 182 px, scroll-padding-top задан 156 px. Summary начинается y=176.44, верх строки перекрыт шапкой. При переходе #apps начало секции y≈155.69 тоже под header, хотя её внутренний отступ спасает текст.
Доказательства: recheck-edge.json, recheck-visual/anchor-320.png; на 375/390 высота header 126 px, текущие 156 px достаточны. Проблема не является общим падением всех якорей.
Приёмка: offset зависит от фактической высоты закрытой шапки (например ResizeObserver→CSS var), учитывает язык, ширину, zoom и переносы; FAQ/title/focus видны целиком при прямом URL и клике из меню. Сохранить offset после закрытия раскрытого меню.

Доказательства и границы: [повторный аудит](../../qa/design-recheck.md).
