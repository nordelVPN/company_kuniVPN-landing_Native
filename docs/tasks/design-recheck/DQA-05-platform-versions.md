# DQA-05 — Убрать одинаковые Other versions без данных версий

Статус: Исправлено: платформенная модель с versions; без данных показана обычная подпись без disclosure. Приоритет: P2.

[Исправления и доказательства](../../qa/dqa-fixes.md). Ниже сохранены исходные факты QA и критерии приёмки.

Основание: docs/06 Apps/platforms прямо запрещает одинаковые dropdown без содержательных вариантов; REV-06. Файл: pages/index.hbs, пять platform-card.
Факт: все пять платформ содержат одинаковые Other versions; раскрытие показывает только Versions and download links have not been provided. В модели нет реального secondary/versions по платформам. Это честная заглушка, но она не выполняет требование осмысленных платформенных вариантов.
Воспроизведение: раскрыть Windows/macOS/iOS/Android/Linux Other versions.
Исправление: условный secondary/versions из данных; при отсутствии — обычная подпись о недоступности, без ложного раскрывающегося выбора. macOS Silicon/Intel и deb и прочие варианты показывать только после подтверждения.
Приёмка: без данных нет одинаковых бессодержательных disclosure; ссылки загрузки остаются недоступными до предоставления URL; картинки телефонов/ПК и разные значки ОС сохранены.

Доказательства и границы: [повторный аудит](../../qa/design-recheck.md).
