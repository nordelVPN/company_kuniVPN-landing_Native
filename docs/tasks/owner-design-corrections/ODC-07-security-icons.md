# ODC-07 — Уточнить иконки security-points

Статус: реализовано; проверено автоматическими сценариями и сравнительными снимками.
Источник: замечания владельца, `docs/images/consept/desktop/04-security.png`, [отчёт ресерча](../../qa/reference-html-research.md).

## Подтверждённая проблема

По замерам `04-security.png`:
- Контейнеры трёх иконок слева (`x=85..178`) имеют размер **`93×83 px`** (тёмные скруглённые блоки с мягкой тонкой рамкой и оранжевым контуром/подсветкой внутри).
- Сами оранжевые иконки внутри имеют размер **`41×49 px`** (замок), **`45×53 px`** (щит с галочкой), **`61×48 px`** (ноутбук + смартфон).
- В текущем HTML (`pages/index.hbs`, `src/templates/partials/icon.hbs`, `src/styles/base.scss`):
  - Размер SVG всего `36×36 px` (`58×58 px` с `padding: 10px` и жёсткой серой рамкой `1px solid #777168`) — почти вдвое меньше визуального веса референса.
  - 3-я иконка (`device` в `icon.hbs`) рисует **настольный монитор на ножке** (`M7 19h7m-4-4v4`), тогда как в `04-security.png` изображён **раскрытый ноутбук + смартфон справа**.

## Правки для разработчика

1. **`src/templates/partials/icon.hbs`**:
   - Уточнить 3 иконки для `#security` (согласованный `stroke-width: 2`, скруглённые углы, `aria-hidden="true"`):
     - `lock`: округлый замок с высокой дужкой и выраженной замочной скважиной по центру;
     - `shield`: щит с чёткой галочкой внутри (пропорции ближе к `04-security.png`);
     - `devices` (или обновить `device`): **ноутбук с широким основанием слева + перекрывающий смартфон справа** (как в `04-security.png`).
2. **`pages/index.hbs` и `src/styles/base.scss`**:
   - Обернуть иконку каждого `li` в `.security-icon` (или стилизовать `.security-points .ui-icon`): размер контейнера на desktop `80–90×76–84 px`, внутренний SVG `44–54 px`, тёмная поверхность `#0d0c0b`/`#121110`, деликатная рамка `1px solid #38332d`, `border-radius: 16px`, цвет линии `var(--accent)`.
   - На mobile (`<=500 px`) пропорционально уменьшить контейнер до `56–64 px`, сохранив выравнивание по верху текста.

## Критерии приёмки

- Все 3 иконки по форме (замок, щит с галочкой, ноутбук+смартфон), толщине линии, масштабу и контейнеру соответствуют `04-security.png`.
- Иконки скрыты от screen reader (`aria-hidden="true"`), не сжимаются (`flex-shrink: 0`) и не ломают сетку на `320 px` в EN/RU.

## Проверка

`npm run build:prod`, `npm run check:build`, сравнительные снимки `04-security.png` vs `#security` на `320/390/1440/1672 px`.
