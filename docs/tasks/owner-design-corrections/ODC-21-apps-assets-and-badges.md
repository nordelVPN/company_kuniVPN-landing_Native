# ODC-21 — Исправить ассеты карточек #apps и стор-кнопки iOS/Android

Статус: реализовано; проверено автоматическими сценариями и сравнительными снимками.
Источник: глубокий ресерч фото-референсов vs готового HTML (`docs/qa/reference-html-research.md`), референс `docs/images/consept/desktop/03-apps.png`.

## Требование

1. Исправить `os-ios.png` в `scripts/prepare-assets.js`: текущий crop (`left:737, top:510, width:60, height:55`) режет левый край бейджа (`L=47.3%`) и захватывает фрагмент буквы `i` из заголовка (`R=32.7%`). Использовать чистую иконку платформы без артефактов обрезки и без дублирования текста `iOS` внутри иконки рядом с `<h3>iOS</h3>`.
2. Убрать непрозрачные прямоугольные вырезки (`alpha=false`) у `windows-device.webp`, `macos-device.webp`, `ios-device.webp`, `android-device.webp`, `linux-device.webp`, которые выглядят как прямоугольные заплатки поверх градиентной диагонали `.platform-card`: подготовить чистые прозрачные ассеты устройств (или согласовать фон карточек без видимых швов обрезки).
3. Привести визуальное оформление кнопок платформ к `03-apps.png`: оранжевые CTA для Windows/macOS/Linux и тёмные стор-бейджи для iOS (App Store) и Android (Google Play), сохраняя честный статус недоступности скачивания до публикации сборок.

## Критерии приёмки

- `os-ios.png` не содержит фрагментов соседних букв и не обрезан по краям.
- На всех 5 карточках устройств отсутствуют видимые прямоугольные границы вырезки поверх диагонального фона `.platform-card`.
- Кнопки iOS/Android визуально соответствуют стор-бейджам из `03-apps.png`, без имитации рабочих ссылок загрузки.

## Проверка

Перегенерировать ассеты, проверить `build:prod`, `check:build`, визуальное сравнение `03-apps.png` vs `#apps` на 1672/1440/390/320 px (EN/RU).
