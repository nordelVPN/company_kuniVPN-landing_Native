# ODC-17 — Главная кнопка Home

Статус: реализовано; проверено автоматическими сценариями и сравнительными снимками.

Источник: последнее замечание владельца и desktop/01-home.png. [Доказательства](../../qa/deep-reference-review.md), [сравнение](../../qa/deep-reference/index.html#home).

В pages/index.hbs класс button large не имеет отдельного правила SCSS. Текущая кнопка EN 167.95×53 px, текст 16 px, без иконок. Референс содержит крупную Download KUNI VPN с download слева и chevron справа (приблизительно 415×78 px при ширине оригинала 1672).

Восстановить масштаб, форму, типографику и иконки CTA отдельным вариантом компонента. Не увеличивать все кнопки глобально. Переход должен оставаться рабочим к разделу приложений до появления реальных загрузок; не имитировать скачивание.

Приёмка: снимки EN/RU при 320/390/1672/1920, без переполнения, доступное имя ссылки и видимый keyboard focus. SVG декора скрыть от accessibility tree. Проверить соответствие соседних платформенных значков и отступов. Не закрывать задачу только по наличию класса large.
