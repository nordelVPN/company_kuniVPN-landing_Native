# ODC-03 — Устранить обрезку home-art.webp

Статус: реализовано; проверено автоматическими сценариями и сравнительными снимками.
Источник: замечания владельца, `docs/images/consept/desktop/01-home.png`, [отчёт ресерча](../../qa/reference-html-research.md), [визуальный аудит](../../qa/deep-reference-review.md).

## Подтверждённая проблема

1. В `scripts/prepare-assets.js` для `home-art.webp` (`left: 480, top: 94, width: 1192, height: 706`) выполняется грубая ступенчатая очистка альфы `cut = y<280?420 : y<360?360 : y<420?290 : y<490?210 : y<590?190 : 0`. Она жёстко режет **`162` видимых нечёрных пикселя** прямо по контуру коллажа, создавая заметные ступенчатые «выкусы» слева.
2. Верхняя кромка (`top: 94`) обрезает `22.5%` видимого контента (в `01-home.png` верхние элементы начинаются от `y=70`), а нижняя — `79.5%`.
3. В `src/styles/base.scss` `#home .section-art` (`position: absolute; right: 0; bottom: 0; width: min(74vw, 1192px)`) на `1440 px` перекрывает текстовую колонку `.hero-copy` на **`398×458 px`** (на `1920 px` — на `152×487 px`).

## Правки для разработчика

1. **`scripts/prepare-assets.js`**:
   - Удалить пороговую ступенчатую маску `cut` для `home-art`.
   - Захватить полный силуэт композиции из `01-home.png` (включая верхние элементы выше `y=94`, если они не заходят на текст шапки, и без резкого ступенчатого обрыва слева; прозрачность чёрного фона `#050404` сделать плавной по яркости/маске без «выкусов»).
   - Перегенерировать `home-art.webp` и `home-art-small.webp` (`npm run assets:prepare`), обновить `width`/`height` в `pages/index.hbs`.
2. **`src/styles/base.scss`**:
   - Согласовать геометрию `#home .hero-copy` и `#home .section-art` (совместно с `ODC-01` и `ODC-20`), чтобы персонаж, ноутбук, щит и декор были видны целиком и не накладывались на заголовок/кнопку на `1440/1672/1920 px`.
   - На `<=900 px` убрать отрицательный сдвиг `margin-left: -12px; width: calc(100% + 24px)`, если он вызывает обрезку краёв, и оставить чистое масштабирование `width: 100%; height: auto; object-fit: contain`.

## Критерии приёмки

- В `home-art.webp` отсутствуют ступенчатые артефакты обрезки (`hardAlphaCutContentPx = 0`).
- Лицо персонажа, наушники, ноутбук, щит и верхний/нижний декор не обрезаны на desktop (`1440/1672/1920 px`) и mobile (`320/390 px`).
- Иллюстрация не перекрывает заголовок, лид и кнопку CTA.

## Проверка

`npm run assets:prepare`, `npm run build:prod`, `npm run check:build`, сравнительные снимки `01-home.png` vs `#home` (EN/RU).
