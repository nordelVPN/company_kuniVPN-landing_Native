## Правки для разработчика

1. **`src/styles/base.scss`**:
   - Ввести явную типографическую шкалу через `clamp()` для заголовков, `.lead`, `p`, заголовков карточек (`.benefits h3`, `.everyday h3`, `.security-points h3`, `.topic-card h3`, `.plans h2`, `.form-card h1`) и CTA-кнопок.
   - Согласовать шкалу с новой плотной гарнитурой WOFF2 из `ODC-20` (не применять глобальный `zoom`/`transform: scale()` ко всей странице).
   - Убедиться, что на `320 px` и `390 px` длинные русские и английские слова (`Безопасность`, `Приложения`, `Troubleshooting`) не вызывают горизонтального переполнения (`overflow-wrap: anywhere` там, где необходимо, без разрыва коротких слов).

## Критерии приёмки

- Визуальная иерархия и масштаб текста в каждом разделе соответствуют референсам на `1672/1920 px` и остаются читаемыми без обрезки и overflow на `320/390/768 px` (EN и RU).
- Приложены сравнительные снимки до/после.

## Проверка

`npm run build:prod`, `npm run check:build`, Playwright (`320/390/768/1440/1672/1920 px`, EN/RU), проверка `scrollWidth === innerWidth`.
