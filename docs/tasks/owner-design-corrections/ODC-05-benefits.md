# ODC-05 — Восстановить четыре преимущества под Home

Статус: реализовано; проверено автоматическими сценариями и сравнительными снимками.

## Требование

Сразу после hero Home и до hero Features добавить самостоятельную тёмную полосу из четырёх HTML-карточек: Stronger Privacy, Reliable Access, Secure Browsing, Multi-Platform. Источник — desktop/01-home.png, а не 02-features.png. Иконки shield, lightning, layers, desktop+phone стоят слева от текста; между карточками вертикальные разделители. Предусмотреть EN/RU.

Светлая полоса в Features — отдельный компонент по 02-features.png (More Privacy, Reliable Access, Safer Browsing, Use It on Your Devices). Нельзя считать её заменой отсутствующей полосы Home или просто перенести её. Аналогичный тёмный блок присутствует в 03-apps.png и 06-login.png; предусмотреть переиспользование с отдельной композицией светлой версии.

## Приёмка

Проверить порядок DOM, все четыре названия и иконки, тёмный фон, горизонтальную структуру desktop и отсутствие скрытых пунктов на mobile. Сравнения EN/RU при 320/390/1672/1920. Не копировать неподтверждённые продуктовые обещания из подписей концепта.

[Аудит](../../qa/deep-reference-review.md) · [Галерея](../../qa/deep-reference/index.html#home). Исправление только документации не означает выполнения реализации.
