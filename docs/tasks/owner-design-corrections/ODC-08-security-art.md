# ODC-08 — Устранить обрезку security-art.webp

Статус: реализовано; проверено автоматическими сценариями и сравнительными снимками.
Источник: замечания владельца, `docs/images/consept/desktop/04-security.png`, [отчёт ресерча](../../qa/reference-html-research.md).

## Подтверждённая проблема

1. В `04-security.png` композиция (щит на светящемся пьедестале, полупрозрачные стеклянные панели, орбита, глобус, молния, шахматка) занимает **`x=650..1670, y=92..929`** (`1020×838 px`).
2. В `scripts/prepare-assets.js` `security-art.webp` обрезается по `left: 760, top: 94, width: 911, height: 780` (`y=94..874`), что срезает:
   - **`110 px` слева** (`L=52.2%` левой кромки — режет стеклянные панели и свечение);
   - **`55 px` снизу** (`B=41.5%` нижней кромки — режет пьедестал, орбиту и шахматку);
   - **`33.6%` сверху** + жёсткий прямоугольный вырез `x < 245 && y > 710` (`8 px` контента).
3. В `src/styles/base.scss` на `1440 px` `#security .section-art` (`width: 61%`) перекрывается с текстовой колонкой `#security > div` на **`106×637 px`**.

## Правки для разработчика

1. **`scripts/prepare-assets.js`**:
   - Расширить crop `security-art` по `04-security.png` до полного охвата (`left: ~650–670, top: 92, width: ~1000–1020, height: ~838`), убрать жёсткий вырез `x < 245 && y > 710`, сделать мягкое удаление чёрного фона `#040303` с сохранением оранжевого свечения и полупрозрачных краёв панелей.
   - Перегенерировать `security-art.webp` и `security-art-small.webp` (`npm run assets:prepare`), обновить `width`/`height` в `pages/index.hbs`.
2. **`src/styles/base.scss`**:
   - Настроить соотношение колонок `#security > div` и `#security .section-art` (например, flex/grid с явным `gap` или без наползания на `1440/1672/1920 px`), чтобы полный щит, панели, орбита и пьедестал помещались целиком без обрезки `height: calc(100% - 40px)` и без перекрытия текста.

## Критерии приёмки

- Щит, пьедестал, стеклянные панели, орбита, глобус, молния и шахматка видны целиком без жёстких срезов по краям.
- На `1440/1672/1920 px` графика не перекрывает текст `#security`; на `320/390 px` сохраняет пропорции и читаемость.

## Проверка

`npm run assets:prepare`, `npm run build:prod`, `npm run check:build`, сравнительные снимки `04-security.png` vs `#security` (EN/RU).
