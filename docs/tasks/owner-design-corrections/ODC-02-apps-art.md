# ODC-02 — Устранить обрезку apps-art.webp

Статус: реализовано; проверено автоматическими сценариями и сравнительными снимками.
Источник: замечания владельца, `docs/images/consept/desktop/03-apps.png`, [отчёт ресерча](../../qa/reference-html-research.md).

## Подтверждённая проблема

1. В `scripts/prepare-assets.js` `apps-art.webp` вырезается по `left: 700, top: 78, width: 971, height: 420` (`y=78..498`), тогда как реальная композиция в `03-apps.png` занимает `x=550..1670, y=74..514`. Попиксельный аудит кромок показал жёсткую обрезку: `T=17.3%`, `B=57.9%` (срезаны `16 px` низа ноутбука/телефона/свечения), `L=14.3%` (срезаны `150 px` слева), `R=58.8%`.
2. В `src/styles/base.scss` `#apps .section-art` задан `position: absolute; right: -20px; bottom: 0; width: 66%`, что на `1440 px` создаёт перекрытие с текстом (`124×286 px`) и сдвиг за правый край контейнера.

## Правки для разработчика

1. **`scripts/prepare-assets.js`**:
   - Расширить область экспорта `apps-art` до полного охвата устройств и свечения в `03-apps.png` (ориентир `left: ~550–600, top: 74, width: ~1070–1120, height: ~440`, без среза нижней базы и левого свечения), убрать грубую ступенчатую альфа-маску `y < 195 ? 150 : 0`, заменить мягким прозрачным удалением чёрного фона (`#040303`) либо аккуратной маской по силуэту.
   - Обновить `width`/`height` в `pages/index.hbs` под новые размеры `apps-art.webp` и перегенерировать `apps-art-small.webp` (`npm run assets:prepare`).
2. **`src/styles/base.scss`**:
   - Убрать `right: -20px` у `#apps .section-art`, настроить ширину/позиционирование так, чтобы на `1440/1672/1920 px` композиция полностью помещалась справа от текстовой колонки без обрезки и без перекрытия заголовка/лида.
   - Проверить адаптацию на `<=900 px` и `320 px` (`object-fit: contain; height: auto;`).

## Критерии приёмки

- Монитор, ноутбук, смартфон, щит, корона и нижнее свечение видны целиком без обрезанных кромок на `320/390/768/1440/1672/1920 px`.
- Нет перекрытия непрозрачной части графики с текстом `#apps` и нет горизонтального переполнения.
- `docs/qa/asset-registry.json` обновлён скриптом `npm run assets:prepare`.

## Проверка

`npm run assets:prepare`, `npm run build:prod`, `npm run check:build`, сравнительные снимки `03-apps.png` vs `#apps` (EN/RU).
