# kuniVPN — актуальные требования и задачи

> **Единый стандарт экосистемы (приоритет):** все 4 лендинга экосистемы `VPN_commerce` имеют единое функциональное поведение и отличаются **только внешним видом (дизайном, палитрой, брендом)** и назначенной тарифной сеткой. См. [общую документацию VPN_commerce](../../docs/README.md).

## Профиль проекта по единому стандарту

- **Тарифная сетка:** **Сетка B** (общая с N1X VPN), основная валюта — **EUR (`€`)**:
  - `Trial` (Триал — 1 месяц) — `€1` · 5 устройств · Один раз для нового пользователя
  - `1 месяц` — `€7` · 5 устройств · —
  - `3 месяца` — `€15` · 5 устройств · `€5` в месяц (справочно)
  - `12 месяцев` — `€55` · 5 устройств · `€4.58` в месяц (справочно)
- **Целевые языки (единые для всех 4 сайтов, 12 языков):** `en` (по умолчанию), `pl`, `uk`, `lt`, `tr`, `ro`, `de`, `sk`, `hr`, `sr`, `bg`, `hu` (см. [единый контракт i18n](../../docs/architecture/i18n.md) и [07-i18n.md](07-i18n.md)).
- **Целевой состав страниц и функций (единый для всех 4 сайтов):** основной лендинг (`index.html`), регистрация (`create-account.html`), вход в аккаунт (`login.html`), восстановление пароля (`forgot-password.html`), личный кабинет (`account.html`), checkout-модал, а также **Telegram-вишлист на PHP 8.4 + Docker Compose** по [единому стандарту](../../docs/architecture/telegram-wishlist.md).

## Приоритет и целевой результат

Уточнения владельца имеют приоритет над старым планом и концептами тарифов. Основные экраны объединяются в index.html; Log In находится на отдельной login.html (ODC-13). Checkout — модальное окно выбора плана. Forgot password, Create account и My Account — отдельные страницы. Папка `images/consept/mobile/` обязательна для проработки мобильных компонентов и состояний; концепты телефонов не заменяют адаптивную вёрстку.

Обязательны логотип из logo-refined-03.png, удаление language-label, светлая полоса features с рваными переходами, предметная инфографика, переработанные platforms/security/support.

## Данные и ограничения

[Тарифы](04-pages-and-components.md#актуальные-тарифы-kunivpn) соответствуют **Сетке B** (четыре предложения, по 5 устройств, основная валюта — **EUR (`€`)**). Целевой набор языков расширен до единого стандарта из **12 языков** (`en` по умолчанию + 11 европейских языков); выбор сохраняется между страницами. Удаление language-label не отменяет доступного имени переключателя. [Контракт i18n и проверки](07-i18n.md).

Нужны лицензированные исходники графики/шрифта, download URL, домен, юридические тексты, подключение PHP 8.4 Telegram-вишлиста и backend-контракты. Код переработан, ассеты экспортированы по реестру; отдельные перекрытые слои в плоских PNG отсутствуют. Статусы и незакрытая визуальная приёмка указаны в актуальном отчёте.
