Исторический аудит до исправлений. [Текущий результат QA/REV](rework-result.md) содержит выполненные изменения и новые проверки.

Дата по локальным часам: 2026-11-20. ОС Windows, Node v24.21.0; целевая среда docs/CI — Node 22. Проверялась существующая установка node_modules, без npm ci. Чистая установка и Node 22 этим прогоном не подтверждены.

## Вывод

Техническая сборка исправна на текущей среде, но реализация не соответствует новой структуре и составу интерфейса. Готовность к приёмке не подтверждена. Найдены 9 групп проблем: 6 P1 и 3 P2. [Файлы задач для разработчика](../tasks/qa-audit/README.md) содержат факты, воспроизведение, файлы и критерии приёмки, со ссылками на существующие REV.

Прочитаны README, docs/01–06, актуальный backlog и прошлый QA-отчёт; проверены манифест, конфигурации, workflow, страницы, partials, стили, main/i18n, локали и скрипты проверок. Наличие PNG в desktop/mobile подтверждено списком файлов. В этом прогоне изображения не просмотрены визуально; предметная спецификация взята из docs/06. Pixel-perfect выводов нет.

Повтор пробы: сначала npm run build:prod, затем node docs/qa/audit-current.cjs. Это диагностический скрипт текущего состояния, не окончательный тест новой приёмки: отсутствие требований печатается как факт, а не код падения. Его VM использует упрощённые DOM-объекты и заглушку перевода, поэтому не проверяет layout, native validity, accessibility tree и runtime i18n. Параметры тарифов/URL/fallback/change проверены существующим check-plans с теми же ограничениями DOM-модели.

## Что работает и нужно сохранить

Единая модель четырёх тарифов и пять устройств, справочные эквиваленты, честные пояснения про API/оплату/загрузки. Общие layout/partials, относительные URL, основные тексты в HTML, lang=en для английской сборки. Focus-visible, labels, skip-link, aria-live, Escape для меню и reduced-motion предусмотрены кодом, но их фактическая браузерная доступность ещё не принята.

## Ограничения и оставшаяся приёмка

Browser не подключился сначала к dev URL 3217, затем к 127.0.0.1:3218, пока отдельный локальный Node HTTP-сервер сообщал о работе (45 секунд). Причина соединения не установлена. Второй сервер завершился по таймеру; после прогона процессов/слушателей 3217/3218 не обнаружено. Уже занятый 3000 и его процессы не изменялись.

Не выполнены: скриншоты реализации/PNG сравнения, Chromium/Firefox/WebKit, overflow/targets на шести ширинах, реальная клавиатура/экранная клавиатура, focus trap, 200% zoom, измерение контраста, console/network audit в браузере, фактический HMR при правке, удалённый GitHub Actions/deploy. Отсутствуют Playwright/Puppeteer в верхнем уровне node_modules; дополнительные зависимости не устанавливались.

Открытые данные из docs: валюта/коммерческие условия, языки первого релиза, лицензии/исходники, download URL, юридические тексты, auth/account/payment API. Это ограничения интеграций, не доказанные баги API.

Изменения этого аудита: новые docs/qa/current-audit.md, audit-current.cjs, проверочный лог и docs/tasks/qa-audit/*.md. Код приложения и существующие задачи/QA-история не изменялись; dev/prod артефакты пересобраны. Коммит/публикация не выполнялись.
