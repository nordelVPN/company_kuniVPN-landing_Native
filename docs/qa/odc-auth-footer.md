# ODC-13, ODC-15, ODC-16 — результат

Выполнены три запрошенные задачи.

- ODC-13: создана pages/login.hbs и маршрут login.html; форма удалена с главной. Кнопка Login и возвраты из регистрации/восстановления ведут на login.html. Общий header обеспечивает вход из кабинета. Сохранены валидация, показ пароля, loading, ошибка API и выбор EN/RU. Заголовок страницы — H1; добавлены переводы title/description.
- ODC-15: auth-art больше не обрезает содержимое через overflow:hidden; бумажный и шахматный декор размещены внутри доступной ширины, изображение сохраняет пропорции. Общая правка распространяется на вход, регистрацию, восстановление и checkout.
- ODC-16: footer повторяет все ссылки header, включая бренд/Home, Features, Apps, Security, Support, Plans, Login и Download. Существующие Help и Account сохранены. Навигационные разделы используют общий массив nav. Ссылки переносятся и имеют зоны нажатия не меньше 44 px.

## Проверки

Production build, ESLint, check:build (5 страниц, якоря, ассеты, тарифы, i18n и негативные проверки), HTTP smoke (10 запросов: корень и /preview) прошли.

Playwright: Chromium 18/18, Firefox 18/18, WebKit 18/18 — всего 54 сценария. Новый сценарий проверяет все ссылки footer на всех пяти страницах, соответствие header, HTTP и целевые якоря, отсутствие переполнения, границы изображения, loading и ошибку входа, переход Login под /preview. Матрица: 320/390/768/1440 px, EN/RU. Существующие сценарии проверяют ошибки полей, показ пароля и сохранение языка.

[Снимки до/после](odc-auth-footer/index.html): одинаковые viewport 320/390/1440 × 1000. До — сохранённая сборка перед изменениями; после — новая production-сборка. Выполнен визуальный просмотр иллюстрации на 320 и 1440 px.

Изменены pages/index.hbs, pages/login.hbs, pages/create-account.hbs, pages/forgot-password.hbs, header.hbs, footer.hbs, base.scss, locales.json, webpack/pages.js; обновлены контракт сборки, браузерные тесты, docs/README.md, docs/04-pages-and-components.md и файлы трёх задач. Остальные задачи ODC не входят в этот проход.

Авторизация остаётся существующим прототипом: backend API пока не подключён.
