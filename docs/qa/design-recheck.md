# Повторная проверка дизайна и требований kuniVPN

После этого аудита внесены [исправления DQA-01–10](dqa-fixes.md). Здесь сохранены исходные наблюдения и доказательства до исправлений; текущие статусы находятся в новом отчёте.

Проверено 2026-11-20 после существенной переработки приложения. Текущее состояние функционально заметно ближе к требованиям, но дизайнерская приёмка ещё не пройдена. Выявлено 10 групп оставшихся проблем: 1 P1 по композиции, 9 P2 по отдельным компонентам и поведению. [Задачи разработчику](../tasks/design-recheck/README.md) · [Визуальная галерея](recheck-visual/index.html).

## Метод и доказательства

Проверены актуальные docs/README, дизайн docs/03, компоненты docs/04, предметный разбор docs/06, EN/RU docs/07, предыдущий результат QA/REV; реализация шаблонов, стилей, модулей и существующих тестов. Исходные desktop 01–09 и refined logo просмотрены по отдельности в обзорном масштабе, mobile 01–09 — тремя группами по три. Спорные области сопоставлены с кодом и свежими скриншотами. Мелкие alpha/glow-края на 1x/2x не приняты.

Свежие снимки: существующая матрица шести ширин перезапущена в трёх движках; дополнительно EN-секции при viewport 1672×941 и RU 320/390, с ожиданием загрузки изображений. Первые обзорные JPG прежней реализации использовались только для ориентира, не как доказательство текущего дефекта. Например, старый apps-review.jpg показывает одинаковые OS icons, а свежий en-apps.jpg — уже разные; этот старый дефект не заявлен повторно.

Файлы оригинала содержат header и нижние полосы, новый сайт — один длинный index. Снимок отдельной секции имеет другой crop/высоту; галерея сохраняет это различие. Одинаковая ширина viewport EN использована для семи секций, без требования одинаковой высоты. Checkout/account сравнены по свежим RU 1440. Это визуальный аудит композиции, а не процент pixel-perfect и не автоматический image-diff.

## Что соответствует

- Четыре HTML и семь секций index в правильном порядке; один H1/header/footer, login последний.
- Навигация и закрытие mobile menu, ссылки auth, show password, корректировка ошибок форм работают в существующих сценариях.
- Checkout открывает 4/4 плана, summary/цены/срок/5 устройств корректны; фокус, Tab/Escape/backdrop, scroll lock и reduced motion проверены существующим suite.
- Тарифы 1/7/15/55, эквиваленты 5/4.58 и платный однократный триал; валюта/продление не выдуманы.
- Refined logo вместо текстовой имитации; разные OS icons, PC/phone иллюстрации, светлая features-полоса с отдельными PNG краями, предметные security/support art присутствуют.
- EN/RU, сохранение выбора, blocked storage, FAQ/chips, account tabs/states и локальный preview работают в проверенных сценариях.
- Без JS основной английский текст, 4 плана и login-разметка сохранены.
- API/auth/payment явно обозначены как прототипы; данные не отправляются, реальный успех не имитируется.
- В существующей матрице на 320/375/390/768/1024/1440 горизонтального overflow не обнаружено; это не доказывает отсутствие перекрытия sticky header.

## Границы

Контраст проверялся только для непрозрачных однотонных фонов видимого текста: изображения/градиенты/opacity/focus/state combinations не покрыты; это не полный accessibility audit. Screen reader, native toolbar zoom 200%, физическая мобильная клавиатура/устройства и 1x/2x alpha/glow остаются открытыми. Существующий zoom-тест использует CSS zoom=2, keyboard-тест — уменьшенный viewport; эти ограничения сохранены.

Не повторялись dev/watch, npm ci, удалённый Actions/Pages и публикация. Сеть внешних API не тестировалась, контрактов нет. Лицензированные шрифт/слои и реальные API/валюта/download URL/юридические тексты по-прежнему нужны. Плоские PNG ограничивают точное разделение перекрытых объектов, но не препятствуют исправлению CSS-композиции и найденного поведения.

Итог приёмки: структурные блокеры первого аудита устранены; оставшиеся DQA нужно закрыть до заявления о полном соответствии дизайну и требованиям. Исторические отчёты сохранены, их старые отсутствия не объявляются текущими.
