# Результат переработки QA/REV

После этого этапа QA добавил DQA-01–10. Актуальные [исправления и 51 browser-проверка](dqa-fixes.md) описаны отдельно; результаты ниже относятся к предыдущему проходу.

Проверка: 2026-11-20, локальная Windows. Целевая среда Node 22.23.5; первоначальная установка также проверялась на Node 24.21.0. Новые функциональные компоненты реализованы. Полная финальная послойная графическая приёмка не объявляется завершённой: предоставлены плоские PNG, часть слоёв перекрыта и не существует отдельными файлами.

## Выполнено

- Четыре страницы: index, forgot-password, create-account, account. Старые семь шаблонов и общий временный CSS-art удалены. Index содержит home/features/apps/security/support/plans/login в нужном порядке, один header/H1/footer; login последний экран.
- Единая навигация и якоря со служебных страниц; мобильное меню закрывается после выбора, Escape работает, aria-current назначается одной секции.
- Checkout в native dialog: четыре актуальных плана, синхронизация выбора и summary, цена/срок/5 устройств/условие триала; email, метод оплаты, loading/error. Анимация 200 ms, reduced motion, focus trap, Escape/backdrop/кнопка, возврат фокуса и scroll lock.
- Формы входа, регистрации, recovery и reset. Связанные ошибки полей, исправление ошибки по input, совпадение паролей, show/hide, checkbox, ссылки. Demo-состояния подтверждения/повтора и invalid/expired token. Реальный успех не имитируется; данные не отправляются.
- Кабинет: вкладки с Arrow/Home/End, редактирование профиля, подписка empty/active/expired, payment/billing empty/loading/error/sample, маскированная карта, строки счетов, security/session expiry, язык, help и подтверждение выхода из прототипа.
- Features: светлая полоса четырёх элементов, два независимых прозрачных PNG края; platforms: пять разных вырезок устройств и значки ОС, версии явно отсутствуют; security: исходный shield/glass/glow art и три тезиса; support: книга/чаты, поиск, chips, четыре локальные темы.
- Логотипы horizontal/vertical/compact из logo-refined-03, вариант horizontal на светлом фоне. Исходная геометрия не перерисовывалась. Asset registry и воспроизводимый экспорт; responsive WebP, lazy loading нижних иллюстраций, размеры изображений.
- Локальное product preview по mobile 01–04: connect/disconnect, список/search/favorites/recent, settings. VPN не создаётся. Mobile 05–09 отражены в кабинете, подписке, тарифах, checkout и help.
- EN по умолчанию/RU, доступное имя языка без видимого language-label. Переводятся новые интерфейсы, ошибки и состояния.
- Default dev port 3000; исправлены кеш данных и live reload шаблонов. Для контекстных зависимостей Webpack сообщает изменённую папку: dev-конфигурация публикует reload после завершения сборки. Проба ждёт подключения клиента и переживает штатную навигацию.
- Проверки и CI обновлены: четыре HTML, фрагменты и отрицательные fixtures; реальные browser-сценарии и отдельный browser job, зависимость deploy от browser.

## Графика: остаётся открытым

[Предметный реестр и mobile 01–09](asset-inventory.md) сопоставляет концепты с компонентами. [JSON-реестр](asset-registry.json) фиксирует source/crop/output/alpha/размер/mobile. Основные art — вырезки исходных композиций с масками удаления соседнего UI, а не независимо восстановленные объекты. Скрытые части персонажа, щита, окон, орбит, glow, стекла и декора нельзя точно получить из единственного плоского PNG. Отдельных исходников слоёв нет; генеративное восстановление не использовалось и не выдаётся за оригинал.

После вопроса об исходниках владелец указал `docs/images/consept`. Папка повторно проверена рекурсивно: 19 PNG (10 desktop, 9 mobile), все одностраничные и без alpha; отдельных слоёв, векторных/слоистых файлов и архивов нет. [Факт проверки](source-check.json). Это те же исходные концепты, которые уже использованы для экспорта.

Требуются слоистые или отдельные прозрачные исходники для окончательного закрытия REV-03 и зависимой графической приёмки REV-05–08. Для точного шрифта нужен лицензированный файл. Существующие рисунки устройств и надпись Help Center в книге являются частью предоставленного растра; они не заменяют локализованный HTML. Варианты logo сверяются с source crops; окончательная ручная проверка на 1x/2x и светлом фоне не подменяется переносом пикселей.

Остаются реальные API auth/account/payment, юридические согласия, валюта, подтверждённые версии/download URL и контакт поддержки. Интерфейсы для них есть, серверные операции не реализованы без контрактов.
