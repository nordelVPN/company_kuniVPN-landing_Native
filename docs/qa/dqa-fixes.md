| DQA-10 | Default Account: profile/subscription слева, payment/billing справа; tabs остались для деталей. Overview-кнопки открывают соответствующий tab. Help-card доступна и внутри мобильного кабинета. |

Тарифы, однократный платный триал, неизвестная валюта, EN/RU и явная маркировка прототипов сохранены. Реальные auth/account/payment API не добавлялись.

Новый tests/dqa.spec.js проверяет:

- close/reopen во время pending submit для всех четырёх планов в корне и подпути; отсутствие старого результата спустя 400 ms;
- чистую валидацию после completed submit, смену плана, reset email/метода, корректный submit/busy;
- быстрое переоткрытие во время анимации без преждевременного закрытия/утечки scroll lock, Escape/focus return;
- один активный sample, пустые/истёкшие состояния, overview и мобильную помощь;
- шесть ширин и EN/RU: реальные границы FAQ относительно header, закрытие меню и effective targets;
- якорь после CSS zoom=2 во всех трёх движках;
- смысловую уникальность SVG, отсутствие пустых version disclosure, calendar/selection, mobile auth order;
- геометрические границы art на 1440/1672.

Во всех завершённых browser-прогонах нет зарегистрированных pageerror, console error и HTTP 404. При разработке тест overview сначала считал также скрытую форму редактирования; локатор уточнён до видимых карточек. Проверка zoom затем выявила реальный дефект Chromium, после исправления повторена в трёх движках. Эти промежуточные падения не выданы за финальный PASS.

## Визуальная проверка

[Новая галерея оригинал/факт](dqa-fixes/index.html) и [геометрия/среда](dqa-fixes/capture.json): 70 снимков секций — EN/RU, 320/375/390/1440/1672; дополнительные снимки служебных страниц на 390/1440. Для воспроизведения: node scripts/capture-dqa.js.

Ширина снимка соответствует viewport. Высота viewport временно увеличивается для полного снимка секции, чтобы браузер не терял нижние строки при capture beyond viewport. Header/skip скрываются только screenshot-стилем. Оригинал содержит header и нижние полосы, факт — секцию длинной главной; crop/высота явно различаются. В галерее сохранён одинаковый display scale, процент pixel-perfect не заявлен.

Просмотрены свежие home/features/apps/security/support/plans/login, RU mobile apps и overview кабинета; исправлен обнаруженный при просмотре выход security-art в соседнюю секцию. Системный Arial, исходные плоские PNG, скрытые слои и финальное согласование макетов остаются ограничениями. DQA-01/03 фиксируют выполненную визуальную итерацию, а не подписанную дизайнерскую приёмку.

Ручные screen reader, физическая клавиатура/устройства, native toolbar zoom и финальная alpha/glow-проверка 1x/2x не подменяются автоматическими тестами. CI-конфигурация уже запускает весь suite; удалённый Actions/Pages, публикация и коммит не выполнялись.
