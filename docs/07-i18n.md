# Локализация kuniVPN (единый стандарт 12 языков)

> **Актуальное требование экосистемы:** целевой набор языков унифицирован для всех 4 сайтов `VPN_commerce` — **12 языков** с английским (`en`) по умолчанию. Полная спецификация и коды языков: [единый контракт i18n](../../docs/architecture/i18n.md).

## Целевой список языков (12)

`en` (Английский — по умолчанию / fallback), `pl` (Польский), `uk` (Украинский), `lt` (Литовский), `tr` (Турецкий), `ro` (Румынский), `de` (Немецкий), `sk` (Словацкий), `hr` (Хорватский), `sr` (Сербский), `bg` (Болгарский), `hu` (Венгерский).

*Фактический статус реализации:* на текущий момент в коде реализован базовый каркас `i18n.js` + `locales.json` (первый проход `en`/`ru`); расширение словаря до всех 12 целевых языков выполняется по единому контракту без изменения архитектуры модуля.

## Контракт

- `src/data/locales.json` содержит словари всех подключённых языков с одинаковым набором ключей; бренд (`kuniVPN`) и названия ОС не переводятся.
- Handlebars helper `t` в `webpack/webpack.common.js` генерирует английский HTML сразу при сборке. Отсутствующий английский перевод ключа останавливает сборку.
- `src/modules/i18n.js` переводит текст и атрибуты `aria-label`, `placeholder`, `title`, `content`. Для текста используются отдельные элементы, чтобы сохранить вложенную разметку.
- Переключатель языка имеет доступное имя без видимой `language-label`. Он обновляет `html lang`, `title`, `description` и все помеченные элементы без перезагрузки.
- Ключ `localStorage`: `kunivpn-language`, независимый от других брендов. Неизвестный язык и недоступный storage дают `en`. Язык браузера не меняет первоначальный выбор.
- Событие `languagechange` обновляет результаты поиска FAQ. Сообщения формы и подпись показа пароля переводятся с сохранением состояния. Выбор тарифа и его цена (`€`) не меняются.
- Без JavaScript работает английская версия; переключение требует JavaScript. URL языковые префиксы и отдельная SEO-индексация в текущую реализацию не входят.

## Добавление контента и проверка

Добавлять ключ во все словари в `src/data/locales.json`, выводить через `{{t key}}` и соответствующий `data-i18n` атрибут. Не переводить родителя с вложенными кнопками/ссылками через `textContent`.

`npm run build:prod`, `npm run check:build`, `npm run test:smoke`, `npm run test:browser`. Проверка build включает автоматические проверки i18n: паритет ключей между словарями, английский HTML, переключение языков, сохранение, fallback и недоступный storage. Результаты предыдущего прохода — в [QA/REV](qa/rework-result.md).
