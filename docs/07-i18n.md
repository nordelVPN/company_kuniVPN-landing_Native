# Локализация EN/RU

Реализована поддержка двух языков: `en` по умолчанию и `ru`. Подход сверён с `company_nordel-landing_Native/src/modules/i18n.js`: словарь, английский fallback, атрибуты data-i18n и сохранение выбора.

## Контракт

- `src/data/locales.json` содержит словари en/ru с одинаковыми ключами. Ключи первого прохода — русские строки, новые компоненты используют английские исходные строки; бренд и названия ОС сохраняются.
- Handlebars helper `t` в `webpack/webpack.common.js` генерирует английский HTML сразу при сборке. Отсутствующий английский перевод русского ключа останавливает сборку.
- `src/modules/i18n.js` переводит текст и атрибуты aria-label, placeholder, title, content. Для текста используются отдельные элементы, чтобы сохранить вложенную разметку.
- Переключатель EN/RU имеет доступное имя без видимой language-label. Он обновляет html lang, title, description и все помеченные элементы без перезагрузки.
- Ключ localStorage: `kunivpn-language`, независимый от `nordel-language`. Неизвестный язык и недоступный storage дают EN. Язык браузера не меняет первоначальный выбор.
- Событие `languagechange` обновляет результаты поиска FAQ. Сообщения формы и подпись показа пароля переводятся с сохранением состояния. Выбор тарифа и его цена не меняются.
- Без JavaScript работает английская версия; переключение требует JavaScript. URL языковые префиксы и отдельная SEO-индексация RU в текущую реализацию не входят.

## Добавление контента и проверка

Добавлять ключ в оба словаря, выводить через `{{t key}}` и соответствующий data-i18n атрибут. Не переводить родителя с вложенными кнопками/ссылками через textContent.

`npm run build:prod`, `npm run check:build`, `npm run test:smoke`, `npm run test:browser`. Проверка build включает автоматические проверки i18n: паритет словарей, английский HTML, переключение EN/RU, сохранение, fallback и недоступный storage. Playwright дополнительно проверяет переключение после поиска/ошибки формы/show password/выбора плана, переходы/перезагрузку и blocked storage. Результаты — в [QA/REV](qa/rework-result.md).

Требование EN/RU сохраняется при будущей переработке главной страницы и checkout. Структурная и графическая переработка из visual-rework остаётся отдельной работой.
