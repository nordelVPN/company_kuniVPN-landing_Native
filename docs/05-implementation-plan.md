# План переработки

Актуальные результаты выполнения: [QA/REV](qa/rework-result.md). Ниже — требования и исходный план; статусы реализации следует брать из нового отчёта.

Текущая реализация — первый проход девяти отдельных страниц. Новый план заменяет прежнюю декомпозицию по отдельным features/apps/security/support/login/plans/checkout страницам. Старые успешные технические проверки сохраняются в [истории QA](qa/implementation.md), но не закрывают новые требования.

## Порядок

1. REV-01: уточнить композицию по концептам и подготовить реестр art.
2. REV-02/03: корректный логотип и ассеты, включая рваные PNG-переходы.
3. REV-04: объединить основные экраны в index, убрать language-label.
4. REV-05/06/07/08: features, platforms, security и support.
5. REV-09/10: последний экран входа, восстановление и регистрация.
6. REV-11: выбор тарифа и модальный checkout.
7. REV-12/13: My Account и мобильные компоненты по mobile.
8. REV-14: обновить проверки/CI и провести визуальную приёмку.

Подробные задачи, зависимости, файлы и критерии — [docs/tasks/visual-rework.md](tasks/visual-rework.md). Все задачи реализации открыты. Документация и анализ концептов подготовлены; производственные ассеты ещё не извлечены.

## Неизменные требования

Webpack + Handlebars + SCSS + vanilla JS, dev/prod, lock-файл, npm ci, lint и GitHub Actions сохраняются. Тарифы — по [актуальной таблице](04-pages-and-components.md#актуальные-тарифы-kunivpn). Все четыре предложения на 5 устройств.

- [ ] Логотип совпадает с refined reference; language-label отсутствует.

- [ ] Security/support полностью пересобраны по референсам.
- [ ] Каждый тариф открывает плавный checkout dialog с правильным Order Summary.
- [ ] My Account проработан по блокам и состояниям.
- [ ] Mobile 01–09 сопоставлены с адаптивными компонентами/демо.
